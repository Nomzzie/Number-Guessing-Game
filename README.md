# Number Guessing Game

A classic CLI number guessing game featuring limited attempts, multiple difficulties, tracked highscore, and input validations.

## How to Run?

**Make sure Python 3 is installed on your PC..**

1. Create a new ` .py ` file, copy the code to the created file.
